# Resume Vault Store Template

## Summary

- Keep to 2-3 bullets focused on role fit, domain strengths, and supported differentiators.

## Core Skills

- Group technical capabilities into compact ATS-friendly bullets.
- Prioritize job-relevant stacks, security/auth concepts, and delivery tooling.

## Professional Experience

- Select the highest-signal roles first.
- Keep bullets action-first and outcome-oriented.
- Prefer 3-5 bullets per role after tailoring.

## Selected Projects

- Use only projects that strengthen the target role.
- Prefer projects that prove relevant engineering depth, security thinking, or collaboration.

## Education

- Include degree, institution, graduation timing, and only the most relevant coursework if useful.

## Certifications / Additional Information

- Include supported extra information only: certifications, GPA, volunteer leadership, language support, or other role-relevant details.
- For public examples, prefer generalized organization names and reduced time/location precision where privacy matters.

## Selection Notes

- Prioritize truthful overlap with the JD over broad keyword stuffing.
- Unsupported JD requirements should stay out of the resume body and appear only in analysis output.
- Output should remain compatible with markdown-resume and ATS parsing:
  - plain Markdown
  - compact bullets
  - no tables
  - no decorative formatting
